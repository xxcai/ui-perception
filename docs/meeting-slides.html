结构化文本生成

Native 和 Web 两条独立的 pipeline，统一输出 YAML 格式，对齐 Playwright ARIA Snapshot 规范。

Native Pipeline

ViewHierarchyDumper遍历 DecorView → 过滤不可见节点 → 提取属性 → XML
NativeRoleResolverclass 名匹配 → 属性调整 (clickable→button, scrollable→scroll)
NativeSemanticTreeBuilder集合子项提升 → 状态附加 → Generic 折叠
RefAssigner可交互节点分配 ref = n1, n2, ...
SnapshotRendererSemanticNode 树 → YAML 文本

Web Pipeline

dom-serializer.js注入 WebView → ARIA 可见性 → Role / Name / State 提取 → JSON
WebJsonParserJSON → SemanticNode 树，未知 role → GENERIC
TreeNormalizer连续 text 合并 / 空 generic 折叠 / 重复子文本去除
RefAssigner有效 bounds 节点分配 ref = w1, w2, ...
SnapshotRendererSemanticNode 树 → YAML 文本 (与 Native 共享)

输出示例

Native + Web 混合场景，以 --- Web --- 分隔，ref 前缀区分来源。

- screen:
  - toolbar "HIS Mall":
    - button "Search" [ref=n1]
    - button "Cart" [ref=n2]
  - webview [ref=n3]
  - tabbar:
    - button "Home" [selected] [ref=n4]
    - button "Category" [ref=n5]

--- Web ---

- screen:
  - heading "Flash Sale"
  - list:
    - listitem:
      - link "Wireless Earbuds" [clickable] [ref=w1] [bounds=10,200,350,320]
      - text "$29.99"
  - textbox "Search products..." [ref=w3] [bounds=10,460,350,510]
  - button "Go" [clickable] [ref=w4] [bounds=360,460,400,510]

Pi-Agent 扩展

基于 Pi-Agent CLI 的本地扩展，注册 9 个工具，通过 ADB 端口转发连接手机 SDK。

phone_capture_ui

抓取界面结构化文本

phone_click

点击指定 ref 元素

phone_type_text

向输入框输入文本

phone_swipe

滑动 (上下左右)

phone_long_press

长按指定元素

phone_press_key

按键 (back / enter / home)

phone_check

勾选复选框

phone_uncheck

取消勾选

phone_select_option

选择下拉选项 (Web)
